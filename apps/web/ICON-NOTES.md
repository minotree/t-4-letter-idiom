- 2026-10-24 사용자 제공 연결 심볼을 SVG 경로로 재현했다. 원본 스크린샷에서 픽셀을 추출한 파일과는 구분한다.
- 파란 고리의 가독성을 위해 사용자 후속 요청으로 흰 배경 `#ffffff` 적용. 심볼 파랑 `#123566`·금색 `#f4ad3c` 유지. 이전 초록 배경 `#214e3d`는 대체했다.

- manifest의 512px 아이콘은 maskable 용도로도 사용하므로 심볼을 중앙 안전 영역에 배치했다.
- 사용자 제공 이미지라는 사실이 상표·이용 권리 검증 완료를 의미하지 않는다.
