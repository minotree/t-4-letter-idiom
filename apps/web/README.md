# Web / PWA 실행·검증

## 앱 아이콘 (2026-10-28)

사용자 제공 원본 `assets/app-icon.PNG`를 사용한다. Windows에서 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/prepare-app-icons.ps1`로 브라우저32·Apple180·PWA192/512·여백을 둔 maskable512 PNG를 재생성한다. 원본 디자인과 비율을 보존하며 흰 배경으로 출력한다. manifest·HTML·service worker가 새 PNG를 참조한다. 기존 `icon.svg`는 참조하지 않는다. 설치된 앱 아이콘 반영은 OS에 따라 재설치가 필요할 수 있다.

## 실행

프로젝트 루트에서 Node24.x, pnpm 10.34.7로 실행한다.

```powershell
pnpm.cmd dev
pnpm.cmd typecheck
pnpm.cmd test
pnpm.cmd build
pnpm.cmd --filter @idioms/web preview --host 127.0.0.1 --port 4173 --strictPort
```

개발 서버 기본 주소는 http://localhost:5173 이며 service worker는 개발 중 등록하지 않는다. PWA는 빌드 후 http://127.0.0.1:4173 에서 확인한다. Vercel 도메인 루트(`/`) HTTPS 배포 설정을 준비했다. [Vercel 배포 안내](../../docs/deploy-vercel.md)의 저장소 루트·Corepack 설정을 따른다. 실제 프로젝트 연결·업로드·배포·출시는 사용자가 수행한다.

## 학습·데이터

- 첫 공개 범위는 텍스트 학습이다. 이미지 제작은 보류 중이며 데이터 정제 후 완성해 후속 버전에 추가한다. 이미지 미완성을 텍스트 공개의 차단 조건으로 삼지 않는다.
- `scripts/prepare-data.mjs`가 최종 `sajaseongeo_image_working.csv`를 읽어 한자·독음·뜻만 포함한 `src/data/idioms.json`을 생성한다. 직접 수정하지 않는다. 생성물은 Git 제외 대상이다.
- 시작 성어는 연결 가능한 후보가 있는 성어에서 선택한다. 이전에 만나지 않은 성어를 우선한다.
- 정답으로 연결한 성어 10개가 세션 한도다. 시작 성어도 같은 세션의 정답 후보에서 제외한다. 힌트에만 표시된 후보는 사용 이력에 넣지 않는다.
- 후보가 없는 글자는 비활성화하며, 모든 글자의 후보가 소진되면 10개 이전에도 결과 화면으로 종료한다.
- 입력은 NFC 및 공백 제거 후 독음 일치로 판정한다. 같은 독음의 한자 성어가 여러 후보에 있으면 뜻을 보고 하나를 선택한다.
- 기본 힌트는 모든 후보의 한자·뜻이다. 오답마다 각 후보의 독음을 앞에서 한 글자씩 추가 공개한다. 공개가 끝나도 다시 입력할 수 있다.
- 과거 이력은 이 브라우저의 `idioms:web:history:v1` localStorage에만 저장한다. 로그인·동기화는 없다. 진행 중 세션은 새로고침 시 초기화하며 과거 이력은 유지한다. 저장 불가·손상 시 안내하고 학습을 계속한다.
- 이번 범위에서 만화 이미지는 표시·캐시하지 않는다. 이미지 파일 매핑과 실제 존재 검증은 후속 작업이다. 한자·뜻은 CSV 내용을 그대로 사용하며 별도 편집하지 않았다.

## PWA·캐시

- 영어 단어장 예문에 듣기·느리게·정지를 제공한다. 기기의 영어 음성을 이용하는 브라우저 TTS이며 음성 파일은 캐시하지 않는다. 기기 음성에 따라 네트워크가 필요할 수 있다. 실제 iPhone PWA의 재생·음질·오프라인 여부는 별도 확인한다.

- manifest, 자체 제작 아이콘, 빌드 JS/CSS와 텍스트 학습 데이터를 정적 캐시에 저장한다. API·인증 응답 캐시는 없다. 현재 정적 빌드는 gzip 기준 JS 약 109KB다.
- 최초 온라인 접속과 service worker 설치 완료가 필요하다. 처음부터 오프라인인 접속이나 캐시 미준비 상태는 지원하지 않는다.
- `pwa.ts`가 빌드 내용 해시를 캐시 버전으로 사용한다. 새 worker는 자동 활성화하지 않고, 사용자에게 적용 버튼과 현재 세션 종료 안내를 보여준다. 적용 시 새로고침하고 이전 앱 캐시만 지운다.
- 캐시 삭제 후 온라인 재접속하면 필수 화면·학습 자산을 다시 저장한다. localStorage까지 삭제하면 과거 이력도 사라진다.
- 실제 Android/iOS 홈 화면 설치, standalone 모드, 업데이트의 기기별 처리, 키보드·회전·장시간 복귀는 사용자 기기 확인 대기다. 브라우저 PWA 검사 통과를 네이티브 앱 검증으로 간주하지 않는다.

## 브라우저 회귀 확인

`scripts/check-browser.mjs`는 외부 패키지 없이 Node WebSocket으로 로컬 Chromium CDP를 사용한다. 전용 테스트 프로필과 포트 9223의 headless 브라우저가 필요하다. 테스트 프로필의 Origin 저장소를 초기화하므로 개인 브라우저에 연결하지 않는다.

프로덕션 preview(4173)와 전용 CDP(9223)를 준비한 뒤 루트에서 실행한다.

```powershell
node scripts/check-browser.mjs
```

퀴즈·10문제 종료·화면 폭·오프라인·손상된 이력·캐시 복구·업데이트를 검사한다. 업데이트 검사에서는 로컬 `dist/sw.js`의 캐시 이름을 잠시 바꾼 뒤 finally에서 복구한다. 배포본을 대상으로 실행하지 않는다. 결과·스크린샷은 `tmp/browser-checks/`에 기록하며 커밋하지 않는다.
# 검색·데이터 검수 보완 (2026-10-23)

하단 **영어 학습**에서 3,839개 단어의 알파벳 연결 퀴즈와 단어장을 제공한다. 영어는 별도 로컬 기록을 사용하며 후보에서 정답 단어/예문을 숨긴다. `data/english/words.json`은 기존 영어 프로젝트 JSON의 학습 필드만 이관한 스냅샷이다. 갱신할 때 `node scripts/import-english.mjs <영어 프로젝트 경로>`로 CSV와 JSON을 모두 대조한 뒤 빌드한다. 영어 코드·데이터 청크는 화면 진입 시 불러오되 프로덕션 PWA 설치 캐시에는 포함되어 최초 캐시 준비 후 오프라인 동작한다.

퀴즈는 연결 글자 선택 → 후보 선택 → 선택 후보의 독음 입력 순서다. 오답 힌트와 오답노트는 선택한 후보만 대상으로 한다. 과거 출발 한자성어 기반의 오답 v1은 보존하고 목록에서 제외하며, 새 오답은 v2 저장소에 기록한다. 아래의 이전 오답 설명은 이 변경 전 기준이다.

하단 메뉴의 **한자성어장**에서 전체 915개(기존 한자성어 666개·신규 천자문 249개)를 한글 독음으로만 검색하고 즐겨찾기를 저장할 수 있다. 천자문에는 `출처: 천자문`을 표시한다. 학습완료는 실제 맞힌 정답부터 기록하고 오답노트는 선택한 후보를 틀린 기록이다. 세 기록은 이 브라우저에 저장되며 메뉴 이동은 진행 중인 퀴즈를 유지한다. 새로고침하면 진행 중인 퀴즈는 초기화된다. 천자문 검토 범위와 출제 보류 해제 내역은 `data/cheonjamun/reviewed/README.md` 참조.

후보 검색은 NFKC와 `爲 → 為`를 적용해 `利/利` 같은 코드 차이로 연결이 끊기지 않게 한다. 교정 전 한자 ID 6개와 중복 제거 ID 3개는 명시적인 이력 이전표로 보존한다. 콘텐츠 32개 행의 교정 내역과 추가 확인 범위는 `../../docs/content-audit.md`에 기록했다.
