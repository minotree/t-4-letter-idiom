4. handoff.md의 '독음/뜻 미확인 0건'과 후속 독음 결정 목록을 구분하세요. 확인한 사실, 판본 차이, 해석/운영 결정, 미확인을 별개로 표시하세요.

출력은 data/cheonjamun/evidence/ 새 디렉터리에 저장하세요. 기존 파일이 있으면 새 run-YYYYMMDD-HHMM 하위 디렉터리를 사용하고 경로를 보고하세요. 기존 draft/·앱·AGENTS·progress는 수정하지 마세요.

- 모든 250개 ID를 한 번씩 포함하고 확인한 근거가 없으면 evidence=[]·coverage=missing으로 남기세요. 빈 곳을 추정으로 채우지 마세요.
- 한자 원문만 확인한 근거는 supports에 hanja만 넣으세요. 한글 독음·현대 풀이까지 증명한다고 표시하지 마세요.
- 본인 초안의 풀이를 다시 근거로 제시하지 마세요. 독립 근거가 아닌 모델 자체 설명은 근거로 세지 않습니다.
- 전체 책·페이지 또는 현대 번역 전편을 복제하지 마세요. 출처별 인용 허용 범위를 지키고 반복 발췌 합계도 고려하세요. 발췌를 저장할 수 없으면 위치와 비교 설명을 남기고 해당 한계를 표시하세요.
- 별음·판본 이견 55개를 우선 보완하세요. 특히 004·066·140·143·157·183·199·201·239의 독음 및 188/205의 戚 반복을 확인하세요. 근거가 모호하면 단정하지 마세요.

- 과거 입력 파일 부재 사유와 실제 캐시/확인 위치.
- 구절별 한자/독음/뜻 근거 확보 수와 미확인 ID 목록.
- 과거 '전수 검증' 표현 중 확인 범위를 정정할 부분.
- 추가/교정한 출처 정보(판본 서지·권리 등도 확인한 범위만).
