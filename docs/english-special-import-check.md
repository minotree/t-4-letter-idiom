- 특급500개 내부 ID 중복0·현재3339개와 ID 중복0·슬래시로 구분한 철자별 중복0.

- 비표준 단어 문자·CSV 열 수 오류0. 모든 특급 단어에 기존 연결 규칙으로 이어갈 후보가 존재한다. 임의 순서에서 항상10문제를 보장한다는 의미는 아니다.
- 원본의 기존3339개와 현재 JSON의6개 학습 필드가 모두 일치하여 기존 항목을 바꿀 필요가 없다.
- 원본 JSON은 특급에 `special`을 사용하며 이 값을 적용하면 CSV의500개와 모든 학습 필드가 일치한다.
- 합치면3,839개. `EnglishWord.level`은 문자열이며 현재 퀴즈 후보 선정은 난이도로 제한하지 않는다. 추가 후 특급도 일반 영어 후보에 포함된다.

## 실제 추가 시 필요한 작업

1. `scripts/import-english.mjs`에 `특급: 'special'` 매핑 추가. 기존 명령을 그대로 실행하면 현재는 난이도 불일치로 실패한다.
2. 기존3339개 ID·학습 값을 보존하면서500개 추가, 중복/누락 및 CSV/JSON 재대조. 원본 프로젝트는 읽기 전용으로 유지한다.
3. `data/english/source.json`의 CSV/JSON 해시·개수·이관일 갱신. 기존 이관 근거는 진행 기록 등에 보존한다.
4. `packages/shared/test/english.test.mjs`의3339개 기대값 갱신 및 특급 매핑/개수 검증. 표시 개수는 PWA가 source.rows, 토스가 실제 배열 길이를 사용하므로 함께 갱신된다. 토스는 level을 그대로 표시하고 있어 사용자 표시값을 ‘특급’으로 매핑할지 검토할 수 있다.
5. 타입·관련 테스트·PWA/토스 빌드·영어 브라우저 검사. PWA 오프라인 데이터 갱신과 기존 로컬 기록 유지 확인. 번들 크기 증가도 확인한다.

이번 검사는 형식·입력 간 일치·연결 가능성 확인이며, 특급 뜻/동의어/예문/번역의 외부 근거 검수 완료를 의미하지 않는다.
