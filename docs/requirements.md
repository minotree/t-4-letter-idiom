# 한자성어 연결 학습 요구사항

## 한 이음 10문제로 축소 (2026-10-24)

- 한자·영어 모두 정답 10개 연결 시 완주하며 작은 별 1개를 적립한다. 시작 항목은 문제 수에 포함하지 않고, 9문제 이하 중도 종료에는 별을 적립하지 않는다.

## 영어 연결 학습 추가 (2026-10-23)

- 사용자 지정 t-crossword-app의 최종 words_completed.csv와 기존 vocab.json을 대조하여 3,339개 단어를 재사용한다. 원본 프로젝트는 수정하지 않으며 이 앱의 스냅샷은 `data/english/words.json`, 출처·입력 해시는 `data/english/source.json`에 기록한다.
- 하단 영어 학습 메뉴에서 알파벳 선택 → 뜻/품사/글자 수를 보고 후보 선택 → 영어 단어 입력. 정답 단어·예문·동의어는 후보 힌트로 미리 노출하지 않는다. 오답 시 선택 후보만 철자 힌트를 추가하고 오답 기록도 그 후보만 저장한다.
- 맞힌 단어가 다음 출발 단어가 되며 사슬로 누적. 최대10문제, 시작 단어 및 같은 세션 기출 제외, 다른 세션 미출제 우선·소진 시 기출 허용. 후보는40개씩 추가 표시.
- 대소문자·앞뒤 공백은 무시한다. 복합어의 중간 공백/하이픈은 유지하고 영미 철자는 슬래시로 구분된 각각의 철자를 허용하되 입력 답에 선택 알파벳이 포함되어야 한다.
- 영어 단어장에 전체/즐겨찾기/학습완료/오답노트·검색·예문/해석을 제공. 영어 기록은 한자성어와 별도 namespace로 브라우저 저장하며 메뉴 이동 중 세션 유지, 새로고침 시 세션 초기화. 로그인·동기화 미추가.
- 데이터 category는 english. 한자성어와 영어의 정답 입력·후보 규칙은 별도 순수 함수로 구현한다. 기존 앱의 UI·Hook·라우터·즐겨찾기/출제 상태는 가져오지 않는다.

## 자료 종류 식별·출처 표시 (2026-10-23)

- 탐색 구조(2026-10-24): 하단 상위 메뉴는 한자 학습·영어 학습 두 개다. 각 학습 안에 퀴즈 풀기·나의 단어장을 둔다. 학습 간 이동 및 하위 메뉴 이동은 진행 중 퀴즈 상태를 유지한다.
- 두 학습 화면은 같은 패널 폭·여백과 제목/항목 수 → 하위 메뉴 → 학습 안내 → 진행 수/막대 → 문제 카드 순서를 사용한다. 패널 위에는 같은 위치·스타일의 소개 영역을 두며 한자는 ‘아는 말이 이어지면’, 영어는 ‘아는 단어가 이어지면’ 문구를 표시한다.
- 영어 현재 단어 카드에는 데이터에 있는 예문과 한국어 해석을 표시한다. 하단 안내는 현재 선택한 한자/영어 학습에 맞게 표시한다.

- 영어 글자 선택도 한자성어와 동일하게 원래 철자 순서와 중복을 보존한다. `THAT`은 `T·H·A·T`로 표시하며 공백·하이픈 등 알파벳이 아닌 문자는 선택 버튼에서 제외한다.

- 모든 앱 학습 항목은 category=idiom(한자성어) 또는 cheonjamun(천자문)으로 식별한다. 기존 한자성어 CSV는 category 열이 없으므로 로딩 시 idiom으로 분류한다. 검수 중인 천자문 CSV의 category는 그대로 유지한다.
- 기존 한자성어는 출처 라벨을 추가하지 않는다. 천자문에는 현재 카드·후보 목록·연결 사슬 양쪽·한자성어장에서 `출처: 천자문`을 표시한다. 기존 ID와 브라우저 기록은 종류 필드 추가로 바꾸지 않는다.
- 현재 파일의 종류와 역할은 `data/content-catalog.json`에 등록한다. 원본·과거 검수 스냅샷·진행 중 Qwen 입력은 해시/인수인계 보존을 위해 소급 수정하지 않고 경로와 입력 ID로 구분한다. 후속 통합 데이터에는 category를 반드시 포함한다.
- 후속 통합: `data/cheonjamun/reviewed/cheonjamun.csv`의 250개를 사용하며 원본 초안을 직접 출제하지 않는다. 기존 666개와 부창부수 중복 1개를 정리해 총 915개다. 기존 부창부수의 ID·분류·뜻은 유지한다. 현재 보류 없음 및 실제 검토 범위는 검토본 README 및 review.json에 기록한다.

## 천자문 추가 준비 (2026-10-23)

- 사용자 확정: 천자문은 네 한자 구절을 한 학습 항목으로 구성한다. 기존 한자성어의 글자 수 제한 없음 원칙과 구분한다.
- 원문 순서와 category=cheonjamun을 보존하는 별도 초안으로 준비한다. 기존 CSV·앱에 반영하기 전 출처·독음·문맥 풀이·중복/판본 차이를 검토한다.
- Antigravity에 출처 조사·자료 생성, 로컬 Qwen에 제공된 자료/근거의 초벌 비교, Codex에 구조 검사·수정/충돌 검토·통합을 분담한다. 지시문은 `docs/prompts/cheonjamun-antigravity.md`, `docs/prompts/cheonjamun-qwen.md`.

## 최신 변경: 후보 선택 후 독음 입력 (2026-10-23)

- 연결 한자를 고른 다음, 후보 목록에서 풀 후보 하나를 직접 선택한다. 후보를 선택하기 전에는 답 입력과 제출을 비활성화한다.
- 정답 판정은 선택한 후보에 한정한다. 다른 유효 후보의 독음이라도 선택한 후보와 다르면 오답이다. 아래 초기 기획의 '어느 후보든 입력하면 정답' 및 사후 동음이의어 선택 규칙을 대체한다.
- 오답은 선택한 후보 ID에 기록한다. 오답 힌트는 선택한 후보에만 제공하며 다른 후보의 독음 힌트를 함께 열지 않는다. 후보를 바꾸면 입력을 비우며, 같은 연결 한자 안에서는 후보별 시도 횟수를 유지한다.
- 오답노트는 선택 후보의 독음을 틀린 기록이다. 과거 출발 한자성어를 기록한 v1 저장소는 수정·삭제하지 않고 새 후보 오답 v2 저장소와 분리한다. 이전 기록이 있으면 정확한 후보를 알 수 없어 목록에서 제외했다는 안내를 표시한다.
- 대언장어에서 대기만성을 선택해 틀린 경우 오답노트에는 대기만성이 남는다. 이후 정답을 맞혀도 복습 기록은 유지한다.

## 목적과 범위

2026-10-23 사용자 설명을 바탕으로 처음 작성했다. 남녀노소 구분 없이 한자성어를 재미있게 학습하도록 한다. 개발 순서는 PWA → Toss → Android → iOS다. 향후 영어 단어도 같은 학습 흐름으로 확장한다. 영어의 연결 규칙과 콘텐츠는 후속 기획 대상이다.

## 사용자가 설명한 학습 흐름

글자 수는 제한하지 않는다(2026-10-23 사용자 확정). 4자 낱말 퀴즈가 아니므로 2자·3자·5자 이상인 한자성어·한자어도 포함한다. 현재 성어의 모든 한자를 선택 대상으로 제공하며, 답안도 해당 항목의 전체 한글 독음을 입력한다. 데이터 검수에서 한자 수와 독음 음절 수의 대응은 확인하되, 길이가 4자가 아니라는 이유로 오류 처리하지 않는다.

1. 시스템이 시작 한자성어를 제시한다.
2. 사용자가 제시된 성어의 한자 중 한 글자를 선택한다.
3. 시스템은 선택한 한자가 포함된 한자성어를 적재된 CSV에서 찾아 퀴즈로 제시한다.
4. 사용자는 여러 힌트를 보고 한글 독음을 직접 입력한다.
5. 시스템은 현재 유효한 후보 중 입력한 한글 독음과 일치하는 성어가 있으면 정답으로 판별한다. 그 성어를 다음 출발 성어로 삼아 글자 선택으로 돌아간다. 오답이면 힌트를 추가한다.
6. 한 세션은 최대 10문제다. 같은 문제의 오답 재시도와 새 문제 출제는 구분해야 하며, 정확한 집계 기준은 아래 미결정 항목에서 확정한다.

같은 세션에서 이미 출제된 성어는 다시 출제하지 않는다. 다른 세션에서는 출제된 적 없는 후보를 우선하고, 해당 글자에 연결되는 미출제 후보가 없으면 과거 세션의 기출 후보를 허용한다. 이 경우에도 현재 세션의 기출 후보는 제외한다. 시작 성어의 기출 집합 포함 여부와 이력 보관 범위는 후속 결정한다.

## 힌트와 답안 화면

### 나의 한자성어장 (2026-10-23)

- 하단 메뉴에서 퀴즈와 한자성어장을 전환한다. 메뉴 전환은 진행 중 퀴즈를 초기화하지 않는다. 새로고침 시 퀴즈 초기화 정책은 유지한다.
- 전체 915개(기존 한자성어 666개·천자문 신규 249개)를 한자·독음·뜻으로 검색하며 검색 정규화를 동일하게 적용한다. 목록에는 한자·독음·뜻·즐겨찾기 별표를 표시하고 40개씩 더 불러온다.
- 전체·즐겨찾기·학습완료·오답노트로 분류한다. 즐겨찾기는 사용자가 별표로 관리한다. 학습완료는 이 기능 추가 후 퀴즈에서 실제로 맞힌 정답만 기록하며 이전 출제 이력이나 시작 한자성어를 완료로 추정하지 않는다.
- 오답노트는 오답을 입력했던 문제의 출발 한자성어를 복습용으로 기록한다. 여러 정답 후보 중 사용자가 무엇을 의도했는지 알 수 없으므로 특정 후보를 틀린 것으로 표시하지 않는다. 이후 정답을 맞혀도 복습 기록은 유지한다.
- 즐겨찾기·학습완료·오답 복습 기록은 브라우저에 각각 저장한다. 로그인·기기 간 동기화는 보류한다. 이미지·예문·유의어는 검수된 자료가 없어 이번 화면에 추가하지 않는다.

- 연결 기록은 퀴즈 위쪽 사슬에서만 표시한다. 중복되는 별도 '나의 연결 여정' 패널은 제공하지 않는다.

- 정답을 입력하면 이전 문제를 없애지 않고 현재 세션의 연결 사슬을 퀴즈 영역 위에 누적 표시한다. 시작 성어와 각 정답 성어를 중복 없이 2열 지그재그 카드로 표시하고 한자/독음/뜻·천자문 출처를 보여준다. 카드 사이 화살표에 이음 글자를 표시한다. 단계별 테두리·배지·10개 완성 강조는 영어와 같은 규칙을 사용한다. 최대 10개 연결을 유지하고 새 세션 시작 시 초기화한다. 새로고침 시 진행 중인 세션 초기화 정책은 기존과 같다.

- 사용자가 추가로 첨부한 화면을 힌트 형식의 기준으로 삼는다. 현재 성어 카드에는 한자·독음·뜻을 표시하고, 각 한자 글자를 선택할 수 있게 한다.
- 선택 글자를 안내한 뒤, 그 글자가 포함된 후보 성어를 번호가 있는 목록으로 보여준다. 각 항목은 후보의 한자 표기와 뜻을 표시한다. 후보 수를 함께 표시한다. 첨부 화면의 7개는 예시이며 고정 개수가 아니다.
- 목록 아래에 한글 독음 직접 입력란과 확인 버튼을 둔다. 오답이면 이해할 수 있는 오류 안내와 추가 힌트를 제공하고 같은 문제를 이어간다.
- 후보 중 어느 성어든 한글 독음을 맞게 입력하면 정답이다. 시스템이 별도의 단일 정답을 미리 정해 제한하지 않는다. 예를 들어 家를 선택한 뒤 家給人足이 유효 후보라면 '가급인족' 입력을 정답으로 처리하고 家給人足을 다음 출발 성어로 표시한다.

- 첨부 화면은 모바일 폭의 웹 참고 화면이다. 상단 학습 요약, 연결 이력, 현재 성어 카드, 글자 선택 버튼을 참고할 수 있다. 화면 속 점수·보상·도전 기록은 아직 확정 요구사항이 아니다. 첨부 이미지의 저장소 파일은 등록되지 않았다.

## 세부 운영 규칙

### 첫 구현에 적용한 임시 기준 (2026-10-23)

아래는 작업을 진행하기 위한 구현 기준이며 사용자 테스트 후 조정할 수 있다.

- 시작 성어는 문제 수에서 빼되 같은 세션 재출제 대상에서는 제외한다. 정답으로 연결한 성어 10개에서 종료한다. 힌트에 표시만 된 성어는 기출 처리하지 않는다.
- 후보 한자·뜻을 처음부터 모두 표시한다. 오답마다 후보별 독음을 앞에서 한 글자씩 공개하고, 모두 공개한 뒤에도 재시도를 허용한다.
- 공백과 Unicode 조합 차이는 정규화한다. 별칭은 임의로 허용하지 않는다. 같은 독음의 후보가 여럿이면 사용자에게 뜻과 한자를 보여주고 선택받는다.
- 연결 후보가 없는 글자는 선택을 막고, 모든 글자의 후보가 소진되면 조기 종료한다. 10문제 연결을 사전 보장하지 않는다.
- 과거 이력은 브라우저 로컬 저장소에 보관한다. 힌트 후보는 먼저 현재 세션 사용 성어를 제외한 다음 과거 미출제 우선 규칙을 적용한다. 시작·정답 성어는 정답 처리 시 이력에 저장한다.
- 진행 중 세션은 새로고침 시 초기화하고 과거 이력만 유지한다. 로그인·서버 동기화는 이번 기능에 필요하지 않다.

### 사용자 테스트 후 후속 결정

- 현재 힌트 난이도·추가 공개 방식의 적절성, 별칭·건너뛰기 필요 여부.
- 이력 초기화 UI 및 진행 중 세션 복구 필요 여부.
- 점수·연속 정답 도입 여부와 후속 이미지 표시 방식.

## 인증·운영 책임

### 공개 범위와 이미지 후속 계획 (2026-10-23 사용자 확정)

첫 공개는 한자·독음·뜻·텍스트 힌트를 이용한 학습으로 진행한다. 이미지 작업은 현재 보류 중이며, 데이터 정제를 먼저 진행한 뒤 이미지를 완성하고 후속 버전에 추가한다. 이미지 제작 완료와 매핑 검증은 텍스트 버전 공개의 선행 조건이 아니다.

현재 CSV의 `image_filename`과 기존 이미지·제작 자료는 보존한다. 텍스트 버전에서는 이미지의 존재를 요구하거나 이미지를 다운로드·캐시하지 않는다. 이미지 기능을 추가할 때 최종 성어·독음·뜻과의 대응, 파일 존재·이용 권한·표시·캐시 비용을 별도로 검증한다. 보류 중인 이미지 제작은 별도 요청 없이 재개하지 않는다.

로그인·기기간 동기화는 검토 중이다. 필요한 기능이 요청되면 에이전트가 필요 이유와 선택지를 다시 알린다. 현재 서버·인증·호스팅을 확정하지 않는다.

승인·출시는 사용자가 수행한다. 에이전트는 그 전까지 구현·설정·검사 및 실행 안내를 준비하고, 사용자 작업이 필요한 시점을 알린다. 업로드·검토 요청·배포·공개 출시를 별도 위임 없이 실행하지 않는다.
# 검색·텍스트 검수 보완 (2026-10-23)

- 후보 검색은 NFKC와 `爲 → 為` 정규화를 적용한다. 원문 표시·ID와 검색 비교를 구분하며, 다른 글자나 독음이 같다는 이유로 성어를 병합하지 않는다.

## 앱 홈 화면 (2026-10-24)

- 영어에서 확정한 지그재그 이음 카드·단계별 색과 완성 강조·10문제 완주 별 등급·후보 플로팅 입력·정답 후 카드 최상단 이동을 한자에도 적용한다. 한자 후보에는 한자와 뜻, 현재/기록 카드에는 독음과 천자문 출처를 유지한다. 영어 전용 동의어·예문·해석은 한자에 추가하지 않는다.

- 영어 정답 처리 후 방금 맞힌 단어 카드의 상단을 화면 위에 맞춘다. 위쪽 이음 기록은 스크롤을 올려 확인한다.

- 영어 제목 옆에 10문제 세션 누적 완주 횟수와 별 등급을 표시한다. 완주1회=작은 별1개, 10회=중간 별1개, 100회=큰 별1개. 123회는 큰1·중간2·작은3으로 분해한다. 큰 별10개 이상은 별과 개수로 압축 표시한다. 시작/중도 종료/9문제 이하는 적립하지 않고 동일 세션은 한 번만 적립한다.
- 영어 완주 횟수는 `idioms:web:english:completed-sessions:v1`에 별도로 저장한다. 기존 학습완료 단어 수로 과거 세션 수를 추정하지 않으며 적용 시점부터 집계한다. 읽기·쓰기 실패는 안내한다. 한자 완주 횟수도 같은 규칙으로 집계하되 `idioms:web:hanja:completed-sessions:v1`에 독립 저장한다.

- 영어 이음 기록의 정답1~10 카드는 초록→청록/파랑→보라→주황→금색(10) 테두리와 색 배경 단계 배지(n/10)로 진행도를 표시한다. 마지막 카드는 금색 배경·10개 이음 완성 문구로 강조하며 기록 상단에 이번 이음 n/10을 표시한다. 시작 카드는 중립색이다. 실제 실력 등급·점수는 부여하지 않는다. 이전 먼셀 색상환 방식은 대체한다.

- 영어 이음 기록은 시작 단어부터 각 단어를 한 번씩 카드로 표시하며 2열 지그재그(오른쪽→아래→왼쪽→아래)로 배치한다. 카드에는 단어·뜻을, 카드 사이 화살표에는 이어 준 알파벳을 표시한다. 읽기 순서는 실제 학습 순서로 유지한다.

- 영어 플로팅 입력창은 선택 카드 아래 공간을 우선하고 부족하면 위에 배치한다. 선택 후보와 겹치지 않도록 실제 높이를 측정하며, 양쪽 공간이 부족하면 공간이 더 넓은 쪽에서 입력창 높이를 줄이고 내부 스크롤을 제공한다.

- 영어 후보의 라디오를 선택하면 선택 카드 근처에 정답 입력창을 띄우고 자동 포커스한다. 후보 목록 스크롤·닫기·Escape·메뉴 이동·정답 처리 시 플로팅을 닫는다. 닫힌 뒤 기존 하단 입력란은 사용할 수 있으며 후보 재선택으로 다시 띄운다. 화면 크기와 가상 키보드의 가시 영역에 맞춰 위치를 보정한다. 한자 후보에도 같은 방식의 플로팅 입력을 적용한다.

- 영어 현재 단어 카드와 단어장에 기존 데이터의 동의어를 표시하며 빈 값은 생략한다. 후보 목록은 첫 줄에 라디오·글자 수·동의어, 다음 줄에 뜻을 표시한다. 동의어가 없으면 첫 줄에는 라디오·글자 수만 표시한다(2026-10-24 사용자 변경).

- 영어 현재 카드의 예문은 계속 표시하고, 한국어 해석은 ‘예문’ 옆 ‘해석 보기/접기’로 펼친다. 처음과 정답 연결·새 세션에서는 접는다. 해석이 없으면 버튼을 표시하지 않는다.

- 앱 표시 이름은 ‘모두의 이음’으로 잠정 적용한다. 상단·하단·브라우저 제목·PWA 이름에 반영하며 패키지명·저장 키는 유지한다. 한자·영어 학습 안내는 ‘이음’, ‘이어갈’ 등 자연스러운 표현을 사용한다. 네트워크의 ‘연결 상태’는 유지한다.

- 현재 문제 카드의 한자 독음 옆 및 영어 품사 옆에 ‘뜻 보기’ 버튼을 제공한다. 뜻은 처음에 숨기고 버튼으로 펼치거나 접는다. 정답 연결·새 세션에서는 다시 접는다. 후보 목록·단어장·사슬의 뜻과 영어 예문 표시는 유지한다.
- 향후 한자 UI 변경을 영어에 확대 적용할 때는 사용자에게 먼저 확인한다. 뜻 보기/접기의 양쪽 적용은 사용자 승인 완료.

- 기본 주소 및 `#home`에서는 한자·영어 학습 선택 홈을 표시한다. 각 카드에 자료 수와 학습 시작 링크, 홈에 간단한 이용 순서를 제공한다.
- 하단 메뉴는 홈·한자 학습·영어 학습이며 상단 브랜드도 홈으로 이동한다. 기존 `#main`·`#idioms`·`#english` 직접 진입은 유지한다.
- 홈을 오가는 동안 기존 학습의 퀴즈·선택·입력 상태를 유지한다. 새로고침 시 진행 중 세션 초기화 정책은 유지한다.
