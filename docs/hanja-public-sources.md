# 한자 음훈 공공·전문기관 출처 조사 (2026-10-31)

## 범위와 결론

대상은 현재 학습 한자 1,566자의 한국어 음·훈이다. 공식 기관 안내·API 문서·공개 이용정책을 조사했다. 전수 항목 대조, 데이터 다운로드·교체, 기관 문의 발송은 하지 않았다. 기존 음훈 데이터와 고지는 유지한다.

공공·전문 편찬기관 자료를 검증 근거로 우선하는 방향은 타당하지만, 1,566자의 음·훈을 모두 제공하면서 앱 내 저장·가공·재배포까지 허용하는 단일 자료는 이번 조사에서 확정하지 못했다. 검색에서 찾지 못한 것을 자료가 존재하지 않는다는 뜻으로 해석하지 않는다.

## 이용조건

표준국어대사전 공식 정책은 별도 명시 없는 자료에 CC BY-SA 2.0 KR을 적용하며 상업적 이용, 저작자표시, 동일조건변경허락을 안내한다. 출전 있는 용례와 멀티미디어는 별도 조건이다. 실제 채택할 데이터의 적용 범위와 API 이용조건을 추가 확인해야 한다. 이번 조사에서는 우리말샘의 개별 정책까지 확정하지 않았다.

공공기관 홈페이지에서 열람할 수 있다는 이유만으로 앱에 일괄 복제할 수 있다고 판단하지 않는다. 한국문화정보원 FAQ는 콘텐츠별 공공누리 유형 확인을 안내한다. NCIC는 제2유형 자료의 상업적 이용 제한을 명시한다. 광고 운영 앱에 사용할 자료는 해당 자료의 조건을 확인해야 한다.

### 조건 확인 후 표본 접근 결과

국립국어원 두 사전만 대상으로 竹·行·昃·虢 관련 검색을 시도했다. 검색 도구에서 개별 사전 항목을 확보하지 못했고, 우리말샘 `search/searchResult?query=...` 및 표준국어대사전 검색 화면 직접 열기도 실패했다. API 문서는 인증키 발급이 필요하다고 안내한다. 이번 작업에서 계정 등록·키 발급·인증 API 호출은 하지 않았다.

따라서 **표본의 음훈 일치/불일치 또는 미수록 판정은 전부 미확정**이다. 검색 실패를 해당 한자가 사전에 없다는 뜻으로 기록하지 않는다. 검색에 나온 다른 기관의 문맥 자료·개인 사이트는 표본 근거로 전용하지 않았다. 다음에는 정식 내려받기 파일 또는 API 사용 가능한 환경에서 사전 항목 원문을 확보해야 한다. 키를 채팅·공개 소스에 넣지 않는다.

### 기관 문의안 (미발송)

대상: 단국대학교 동양학연구원 사전 담당 부서. 공식 홈페이지의 최신 담당 창구를 확인한 뒤 발송할 문안이며, 확인하지 않은 이메일 주소를 기재하지 않는다. 한국고전번역원에는 아래 문안을 해당 기관 자료명으로 조정해 사용할 수 있다.

> 제목: 한자 음훈 데이터의 광고 포함 학습 앱 이용조건 문의
>
> 한자 연결 학습 앱 ‘모두의 이음’을 개발하고 있습니다. 앱에서 쓰는 한자 약 1,566자의 한국어 음과 훈을 공신력 있는 자료에 근거하여 제공하고자 합니다. 귀 기관의 사전 자료 중 적합한 데이터와 이용조건을 문의드립니다.
>
> 1. 광고가 포함된 Web/PWA 및 토스 미니앱에서 한자별 음·훈을 제공할 수 있습니까?
> 2. 필요한 항목을 추출하여 JSON 등으로 가공하고 앱 번들에 포함해 오프라인에서도 제공·재배포할 수 있습니까?
> 3. 허용되는 가공 범위, 출처 문구·표시 위치, 라이선스·면책 고지 조건은 무엇입니까?
> 4. API·내려받기·데이터 제공 협약 등 정식 취득 방법, 비용과 요청 제한이 있습니까?
> 5. 훈을 쉬운 표현으로 바꾸거나 복수 음훈을 정리하려면 별도 허락·감수가 필요합니까?
>
> 이미지·폰트·용례·장문 해설의 복제는 이번 문의 대상에서 제외합니다. 허락 가능한 데이터 범위와 조건을 서면으로 안내해 주시면 그 범위 안에서 적용하겠습니다.

## 다음 검토 절차

1. 상업적 앱 내 저장·가공·오프라인 재배포·표시 문구·API/다운로드 조건을 문서나 기관 회신으로 먼저 확인한다. 문의는 사용자가 발송하거나 별도 명시적 위임 후 수행한다.
2. 조건을 충족한 자료만 소수 표본 확인: 竹·行·樂·昃·虢·輶·颻·為·黙·호환 한자. 수록 범위·편찬 주체·버전을 함께 확인하며 표본 결과로 전체 수록률을 확정하지 않는다.
3. 조건이 적합한 원본을 확보하면 입력 해시를 고정하고 결정적 스크립트로 1,566자 누락·복수 음훈·불일치를 추출한다. 대량 비교 초벌은 프로젝트 분담 원칙에 따라 로컬 Qwen에 제공 근거와 함께 맡길 작업 지시를 준비하고, Codex가 수정 제안·충돌·근거 부족을 검토한다. 모델 기억으로 음훈을 확정하지 않는다.
4. 항목별 근거와 실제 반영 범위를 남긴 후 데이터·출처 문구를 함께 갱신한다. 단순 조회·표본 검토만으로 공공기관 제공 또는 전체 검증 완료라고 표시하지 않는다.
