# 개별 한자 음·훈 (2026-10-30)

## 44자 보완 후 현재 상태

- 총 1,566자 모두 음훈을 표시한다. 기존 1,522자와 명시 검토한 44자(호환 38·이체자 2·개별 사전 사실 4)를 합쳤다. `supplements.json`, `supplement-review.md` 참조. 성어 원문을 정규화하거나 치환하지 않는다.
- 각 앱의 `hanja-license.txt`는 `source-notice.txt`에서 생성하며 libhangul 조건과 보완 출처를 구분한다. 아래 44자 확인 중·자동 대응 제외 설명은 보완 전 상태다. 보완 후에는 명시된 44자 대응만 허용하고 미지 글자의 일반 자동 치환은 계속 하지 않는다.

## 최초 추출 기록 (보완 전)

- 입력: `../hanja-research/pilot/source-analysis/libhangul-hanja.txt`의 고정 커밋 원본. `review.json`에 입력 해시·검토 범위·미확인 글자 기록. 원본은 수정하지 않는다.
- 생성: `python scripts/prepare-hanja-readings.py`. 학습 자료 915개에 쓰이는 1,566자 중 1,522자는 원본 음훈 표시, 44자는 확인 중. 호환 한자를 자동 치환하지 않는다.
- `훈 음`을 분리하고 원본 키에만 음이 있는 6자는 키를 음으로 사용한다. 파싱할 수 없는 구절은 `review.json`에 별도 기록하며 앱에 넣지 않는다. 복수 훈음은 모두 보존하고 현재 성어의 의미로 단정하지 않는다. 竹의 `대` → `대나무`만 사용자 승인 표현으로 변경한다.
- 원본 파일 상단의 BSD 3-Clause 저작권·조건·면책 고지를 `libhangul-license.txt`로 보존한다. 각 앱의 준비 명령이 public 고지를 복사하며 팝업에서 출처·조건을 연다. 전체 저장소 라이선스와 개별 데이터 파일의 조건은 구분한다. 원본 고지 외 데이터 기원의 독립적인 권리 보증을 주장하지 않는다.
- 검수: 해시·누락·중복·형태를 스크립트/테스트로 검사. Qwen에는 제공 원본 내 구조 불일치만 분류하도록 지시하며 사전 정의를 기억으로 보완하지 않는다. 전체 1,522자 의미의 사전 교차 검수·전문가 감수 완료를 뜻하지 않는다.
- 화면: 현재 한자 카드에서 글자별 버튼, 훈/음만 표시. 부수·획수·획순은 포함하지 않는다. Escape·닫기·바깥 클릭·화면/성어 변경 시 닫는다.
