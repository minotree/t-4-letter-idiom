# 천자문 앱 검토본 (2026-10-23)

Antigravity 초안 250구절을 Qwen3 14B가 비교했고, Codex가 수정/불확실 85개와 유지 표본 10개(001,003,016,050,080,125,150,175,210,250)를 검토했다. 나머지 유지 항목은 구조 검사만 수행했다. 전문가의 전수 의미 감수 완료를 뜻하지 않는다.

- `cheonjamun.csv`: 출제 가능한 검토본 244개. 원문 sequence/ID를 유지하며 보류 구절 때문에 번호가 연속하지 않는다.
- `review.json`: 초안·근거·Qwen 결과·검토본 SHA-256, 250개 항목별 처리 및 실제 확인 범위.
- 원본 `draft/`, `evidence/`, Qwen 실행 기록은 수정하지 않았다.
- Qwen 수정 제안 79개 중 독음 231(염필윤지 → 염필륜지)만 채택했다. 다른 제안에는 8자 대구의 뜻을 4자에 합친 오류와 기준 판본의 이체자를 바꾼 오류가 많아 채택하지 않았다. 225의 불필요한 ‘특별한 수소’를 고치고, 231은 발명을 단정하지 않는 풀이로 수정했다.

독음 231의 倫=륜과 225의 가축 명칭은 [석봉 천자문 전사본](https://ko.wikisource.org/wiki/석봉_천자문)의 해당 구절에서 확인했다. 뜻의 인물 대응은 [천자문 대조표](https://ko.wikisource.org/wiki/번역:천자문)와 비교했다. 현대 번역문 전체를 복제하지 않았다. 이 자료들은 전사/번역상의 오류 가능성이 있으므로 이후 교정이 가능하다.

기준 원문은 위키문헌 석봉 천자문 전사본이다. 1691년 어제서문이 보이므로 기존 조사 기록의 ‘1583 간행본’ 설명을 해당 전사본의 실제 간행연대로 확정하지 않는다. 고문헌 원문과 현대 번역의 이용 조건은 별개다. 이번 검토본의 한국어 풀이는 초안에서 직접 작성한 문장을 유지·교정했다.

## 앱 통합

`scripts/prepare-data.mjs`가 기존 666개와 검토본을 읽어 JSON을 생성한다. 정규화한 한자가 같은 `夫唱婦隨`는 기존 한자성어 ID·독음·뜻·종류를 유지한다. 이 항목은 양쪽 자료에 존재하지만 화면에는 기존 한자성어로 한 번만 나온다. 따라서 신규 천자문은 243개이며 통합 909개다. 천자문 출처 표시는 신규 항목의 카드·후보·사슬·한자성어장에 적용한다.

원본 CSV를 합쳐 덮어쓰지 않는다. 검토본 변경 후에는 검토 기록과 해시를 함께 갱신해야 하며, 앱 준비 단계에서 불일치를 거절한다.
