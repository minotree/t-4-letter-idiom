# 표준국어대사전 학습 보완 정보

2026-10-12 사용자 내려받기 XML 88개, 총 436,587항목을 읽기 전용으로 처리했다. 입력 파일명·SHA-256은 `source.json`에 보관한다. 원본 전체 XML은 저장소에 복사하지 않는다.

## 적용 범위

- 학습 915항목 중 독음과 한자 표기가 모두 정확히 일치하는 488개에 사전 정보 제공. 연결되지 않은 427개는 `unmatched.json`에 기록한다. 검색 실패·사전 미수록의 확정 판정이 아니라 엄격한 연결 기준에 맞지 않은 항목이다.
- 표제어의 하이픈·캐럿·공백만 제거하며 두음법칙·유사 독음·이체자·호환 한자 치환은 하지 않는다. 원어 구성요소가 모두 한자인 항목만 사용한다. 복수 표제어 후보는 자동 채택하지 않는다.
- 뜻풀이·품사·발음 텍스트·관련어·사전 항목/의미 식별자를 선택한다. 음성·이미지·출전 있는 용례를 포함한 모든 예문은 제외한다. 여러 의미는 원본 순서로 함께 보여 준다.
- 기존 학습 뜻·한자·독음·ID·정답 규칙과 libhangul 음훈은 유지한다. 이 작업은 의미 차이의 전수 전문가 검수나 기존 뜻 교정이 아니라 정확한 표제어에 대한 사전 보완 정보 연결이다.
- PWA·토스의 한자 현재 카드 및 단어장에 독립 구현한 `DictionaryDetails.tsx`로 펼쳐 표시한다. 후보 목록에는 추가하지 않는다. 영어는 적용하지 않는다.

## 재생성·검사

```powershell
python scripts/inspect-stdict.py '<사용자 XML 디렉터리>'
node scripts/prepare-stdict.mjs
node scripts/check-stdict.mjs
```

먼저 일반 앱 준비 명령으로 `apps/toss/src/data/idioms.json`을 최신 학습 자료에서 생성한다. 검사 스크립트는 입력을 읽어 `tmp/stdict-inspection.json`을 생성하며, 두 번째 명령이 이 디렉터리의 파생 데이터를 갱신한다. 다른 내려받기 버전 사용 시 `prepare-stdict.mjs`의 날짜와 수록 범위를 검토·갱신해야 한다. 원본 경로를 프로젝트 설정에 고정하지 않는다.
