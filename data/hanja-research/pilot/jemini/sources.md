# Sources (출처 조사 보고서)

## S1
- **제공자·문서명:** 국립국어원 표준국어대사전 / 한국한문교육학회 한자 정보 기준
- **직접 URL:** https://stdict.korean.go.kr
- **실제 열람 여부와 확인 날짜:** 미실행 (원칙 1, 2에 따라 외부 브라우징을 통한 실시간 원문 열람은 보안 샌드박스 환경상의 제약으로 미실행됨)
- **뒷받침하는 항목:** 대상 10자의 한국어 훈·음, 부수, 총획수 기본 메타데이터
- **이용 조건 및 근거 URL:** 공공누리 제1유형 또는 국립국어원 이용약관 (출처 표시 조건)
- **확인 한계:** 오픈소스 획순 SVG 벡터 데이터(예: KanjiVG 등)와의 1:1 매칭 URL 및 라이선스 세부 조항은 미실행 상태임.

## S2 (획순 애니메이션 후보 예시)
- **제공자·문서명:** KanjiVG (Kanji Vector Graphics) / Wikimedia Commons Stroke Order Diagrams
- **직접 URL:** https://kanjivg.tagaini.net
- **실제 열람 여부와 확인 날짜:** 미실행 (직접 URL 열람 미실행)
- **뒷받침하는 항목:** 획별 SVG 경로 데이터 및 획순 애니메이션 구현용 XML/SVG 구조
- **이용 조건 및 근거 URL:** Creative Commons Attribution-Share Alike 3.0 License (CC BY-SA 3.0)
- **확인 한계:** 일본어/중국어 표준 자형(예: 曜, 黄/黃, 暉/輝 등)이 포함되어 있어 대한민국 교육용 한자 표준 자형 및 획순과 미세한 차이가 있을 수 있음. 앱 내 상업적 번들 시 라이선스 전파(Share-Alike) 조건 검토 필요.
