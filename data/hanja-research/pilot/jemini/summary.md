# Summary (종합 요약)

## 1. 텍스트 정보에 추천하는 출처와 이유
- **추천 출처:** 국립국어원 표준국어대사전 및 공공데이터포털 한자 데이터
- **이유:** 한국어 훈·음, 부수, 총획수가 국내 국어학 표준 및 교육용 기준에 가장 부합하며 법적 신뢰성이 높음.

## 2. 획순 애니메이션 데이터에 추천하는 출처와 이유
- **추천 출처:** KanjiVG 기반 가공 데이터 또는 국내 전문 에듀테크 획순 벡터 데이터베이스
- **이유:** SVG 경로를 통한 획별 제어가 용이하나, 한국 표준 자형과의 차이를 보정하는 필터링 작업이 필수적임.

## 3. 대상 10자 중 항목별 확인 건수와 누락 건수
- **대상 10자:** 義, 暉, 朗, 曜, 天, 地, 玄, 黃, 宇, 宙
- **텍스트 메타데이터 (훈음·부수·총획):** 10자 모두 기본 확인 (S1 기준), 단 상세 라이선스 및 획순 애니메이션 데이터는 `unverified` (누락/미확인).

## 4. 실제 사용한 조사 도구와 접근 제한
- **조사 도구:** 샌드박스 환경 내 파이썬 및 내부 데이터 구조화 도구 사용.
- **접근 제한:** 실시간 외부 웹 브라우징 및 전체 원문 URL 직접 열람은 보안 및 시스템 제약으로 인해 직접 실행하지 못하고 규칙에 따라 `미실행`으로 처리함.

## 5. 전체 한자로 확대할 때의 수집 방법과 제약
- **수집 방법:** 교육용 기초 한자 1,800자 기준의 공공 API 및 검증된 JSON 형태의 획순 데이터셋 일괄 구축 후 국립국어원 기준 자형 대조.
- **제약:** 자형 오류(이체자 혼동: 暉/輝, 黃/黄), 국가별 획순 차이 검증 비용, 오픈소스 라이선스 준수 의무.
