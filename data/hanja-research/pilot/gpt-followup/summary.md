## 조사 도구와 실제 제한
- 실행: 웹 검색, 웹 HTML 페이지 직접 열기, GitHub 파일 항목별 10 URL 접근 시도, Python Unicode 코드포인트 계산, JSON 및 출처 정합성 검사.
- 실행 못함: raw SVG/XML 다운로드·파싱(웹 도구가 image/svg+xml을 거부; 컨테이너 외부 네트워크 DNS 실패), 원본 파일 SHA-256 계산, 실제 획순 렌더링, 한국 교과서 획순 대조, 한국어기초사전 API 호출, 10자별 지역폴더 대안 전수 조사.
- 404는 2026-10-30 조사 시점 개별 한국 SVG 경로의 결과로만 기록.

## 전체 한자 확장 방법
1. 한자 코드포인트를 원형대로 확정하고 정규화·이체자 대체를 자동으로 하지 않음.
2. 한국 정부 사전에서 훈음/부수/획수 수집 범위와 공식 API 허용 조건 점검(출처별 계보, 라이선스 코드, 다운로드 시각 저장).
3. AnimCJK 한국 SVG를 우선 매칭, 미존재는 중·일 폴더 및 Make Me a Hanzi 등으로 단계적 후보 생성하되 한국 검수 전 승인 금지.
4. 각 벡터 SVG를 로컬에서 파싱하여 획별 path, 진행 방향, 총획, 지역 폴더/원본 commit SHA, 무결성 해시 저장.
5. 한국 교재·전문가 기준 대조 결과를 `verifiedBy`, `reviewDate`, `region`으로 독립 기록.
6. 출처별 APL/CC BY-SA/LGPL/MIT 조건 고지 관리 및 상업 번들 설계를 법률 검토 후 확정.
7. PWA/토스 미니앱/모바일 각각 로컬 SVG의 오프라인·성능·접근성 테스트.
