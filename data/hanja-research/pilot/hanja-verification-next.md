# 暉 획순 및 朗 획수 확인 (2026-10-30)

## 暉 획순

- 후속 확인: 사용자가 제공한 WORDROW 暉 획 시작점 1~13번 화면을 시제품 `26249-ja.svg`의 순서별 경로 시작점과 육안 대조했다. 왼쪽 日 1~4, 오른쪽 상단 5~7, 가운데 8~11, 하단 가로 12, 마지막 중앙 세로 13의 시작 위치와 순서가 서로 부합한다. 그림상의 비율 차이는 고려했다. 겹치는 표식·시작점만 있는 정지 화면이므로 각 경로의 전체 방향·세부 모양 및 한국 공인 기준 일치까지 입증하지는 않는다. 사용자가 보여준 참고 화면의 획순과 시제품이 시작 순서에서 일치한다는 제한된 비교다.
- WORDROW 영상(사용자 제공 페이지의 가로 MP4, 15.47초)을 임시 다운로드해 재생 프레임을 추출했으나, 이전 작업이 사용자 새 입력으로 중단되어 영상의 13획 전체 방향 대조는 완료하지 않았다. 자료는 `tmp/`에만 있고 앱에 사용하지 않았다.

- 사용자 보고: 일본 자료의 시제품 재생이 잘 보임. 사용자는 획순의 정확성은 모른다고 명시했다. 이 보고를 획순 정확성 승인으로 해석하지 않는다.
- [WORDROW 暉 학습 페이지](https://hanja.wordrow.kr/%ED%95%9C%EC%9E%90/%E6%9A%89/)에 13획 참고용 획순 영상과 단계별 학습 기능이 있다. 해당 페이지는 영상의 출처를 Make Me a Hanzi로 표시하고 교재 기준과 함께 보도록 안내한다. 영상 자체의 각 획을 이번 웹 도구로 직접 대조하지 않았다. AnimCJK의 [출처 고지](svg-local/COPYING.txt)도 Make Me a Hanzi를 기반으로 명시하므로, 이 영상이 독립적인 한국 교육 획순 근거라고 가정할 수 없다. 페이지의 다른 단계별 UI 데이터 계보는 별도 미확인이다.
- [쉬운 한자사전 暉 검색 결과](https://www.sajeonmoa.com/hanja/%E6%9A%89/)에는 13획과 획순 기능이 보이나 원문 열람이 403으로 차단되어 해당 획순·데이터 출처는 확인하지 못했다.
- 결론: 일본 폴더 후보의 한국 학습용 13획 순서·방향은 여전히 미확인. 시제품의 ‘일본 자료 / 한국 학습 기준 대조 중’ 표시를 유지한다.

## 朗 총획

- [국립국어원 한국어기초사전 낭보](https://krdict.korean.go.kr/eng/dicSearch/SearchView?ParaWordNo=41252)는 11획을 표시한다. [한국민족문화대백과사전 낭산문집](https://encykorea.aks.ac.kr/Article/E0012365)도 朗에 11획을 표시한다. 출처 데이터가 실제로 독립적인지는 확인하지 않았다.
- Unicode 17의 `kTotalStrokes`는 10이며 AnimCJK 한국 폴더 SVG는 11개 경로다. 각 자료의 획수 기준·글꼴 차이를 직접 대조하지 못했으므로 충돌은 유지한다. 같은 페이지의 여러 항목을 독립 검증으로 세지 않는다.

## 다음에 필요한 근거

- 暉: 대상 글자를 획 단위로 직접 보여 주고, 데이터의 기원과 한국 교육용 기준을 확인할 수 있는 자료. 각 획의 시작·방향·순서를 일본 후보와 대조한다. 재게시나 Make Me a Hanzi 파생 자료를 독립 근거로 간주하지 않는다.
- 朗: 10획과 11획 각각의 실제 자형·획 분해 및 출처별 획 셈 기준. 확인 전 시제품에서는 총획을 준비 중으로 둔다.
- 이번 조사로 앱 데이터나 획순 검수 상태를 승격하지 않았다. 실제 서비스에 넣기 전 라이선스·오프라인·기기 검사는 별도다.
