# GPT 일괄 출처 조사 인수 및 보완 (2026-10-30)

## 결론

GPT 조사에서 한국어 한자별 훈음·부수·총획을 한 번에 검증하는 재사용 가능 원본은 새로 확인되지 않았다. 다만 GPT가 미확인으로 남긴 한국어기초사전의 공식 전체 다운로드 화면을 Codex가 발견해 JSON 원본과 필드 구성을 검사했다. 다운로드는 가능하지만 한자별 부수·획수 필드로 바로 사용할 수 있는지 확인되지 않았다.

## 제출 내용과 기존 로컬 확인 대조

- `gpt-bulk-sources/source-candidates.md`, `recommendation.md` 인수. GPT는 libhangul 원본 본문과 Unihan ZIP을 열지 못했으며 1,566자 실매칭을 수행하지 않았다. 원본 제출은 보존한다.
- Codex는 앞선 작업에서 libhangul의 고정 커밋 `23d2cd9d10d516d523d60c562dbcc7ea08139a09` 원본 파일 자체의 BSD 3-Clause 헤더와 해시를 확인했다. 파일 출처·추가 권리 및 실제 앱 배포 방식은 여전히 검토 대상이다. 이 파일의 후보 1,522자, 한국용 AnimCJK 파일 교집합 411자는 이전 로컬 검사 결과이며 GPT가 새로 검증한 값이 아니다.
- 국립국어원 [API 공식 문서](https://krdict.korean.go.kr/kor/openApi/openApiInfo)에는 검색 원어와 어휘 상세 원어 필드가 문서화되어 있고 부수·획수라는 필드는 찾지 못했다. 이것은 문서 검색 결과이지 실제 API 응답에 절대 존재하지 않는다는 증명이 아니다. 원어 포함 검색을 지원하나 API 키 발급·샘플 호출·누락 검사는 하지 않았다. API 키를 요청해도 한자 마스터가 확보된다고 가정하지 않는다.
- [Unicode 17 대응 UAX #38](https://www.unicode.org/reports/tr38/tr38-39.html)은 안정된 확정 문서다. `kTotalStrokes`는 IRG 기준으로 CLDR 정렬·전사 목적의 참고 속성이며 한국 교육용 획수로 자동 확정하지 않는다. `CJKRadicals.txt`는 번호와 부수 기호/표의문자 매핑이며 한국어 부수 훈음 사전은 아니다.

## 공식 사전 전체 다운로드 추가 확인

- [국립국어원 전체 다운로드 화면](https://krdict.korean.go.kr/download/downloadPopup)에 2026-10 게시 엑셀·XML·JSON 다운로드 버튼이 있다. 다운로드 화면의 실제 버튼 경로를 확인하고 공개 JSON ZIP을 로컬 임시 폴더에 확보했다. API 키 발급·개인 이메일 입력은 하지 않았다.
- JSON 파일명에 2026-10-19 날짜가 있고 ZIP 크기는 84,498,237바이트, SHA-256 `c8f9ffbf7e9be1f1ec86fa29e4160a75eee8044fc081c27788dadf3ceb66d34e`. 내부 11개 JSON 파일의 비압축 크기 합계는 1,016,275,365바이트다. 원본은 `tmp/krdict-full-json-202610.zip`에만 보관하고 앱에 포함하지 않는다.
- `python scripts/inspect-krdict-dump.py`: ZIP 해시를 검사하고 11개 파일을 압축 해제 없이 순차 읽어 `att` 속성명을 집계했다. `origin` 등 어휘 필드는 확인했으나 한자별 훈음·부수·총획을 나타내는 명시적 `att` 이름은 발견하지 못했다. 첫 JSON 하나는 별도 파싱했고 원어 예시는 한자어 문자열이었다. 결과는 `gpt-bulk-sources/krdict-dump-inspection.json`.
- 이 검사는 `att` 이름의 줄 단위 스캔과 첫 JSON 표본 파싱이다. 전체 JSON 스키마·내용 전수 검증이나 한자별 매칭은 수행하지 않았다. **필드명이 없다는 관찰만으로 다른 구조에 데이터가 전혀 없다고 확정하지 않는다.**

## 남은 판단

- 한국 교육용 부수명·총획의 대량 대조 원본과 라이선스는 미확보. 朗의 사전 11획·Unicode 10획·SVG 11경로 차이는 미해결이다.
- API 키를 사용자에게 요구하기 전에, 현 문서상 한자별 필드 미확인이라는 점과 실제 호출 검사의 목적·한계를 명시해야 한다. 현재로서는 키 발급을 필수로 결론 내리지 않는다.
- 한국용 획순은 AnimCJK 후보의 개별 한국어 학습 기준 대조가 필요하다. 전체 학습 앱 탑재·배포는 하지 않았다.
