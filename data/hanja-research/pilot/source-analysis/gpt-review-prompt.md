# GPT 웹 우선 검수 지시

아래 `priority-review.json`을 이 프롬프트와 함께 첨부한다. 조사 범위는 파일에 있는 48자다. 전체 1,566자를 새로 조사하지 않는다.

```text
첨부 JSON은 한자 학습 앱의 미검수 후보입니다. 실제 웹 원문 확인으로 아래 범위를 검토해 주세요.

범위: libhangul 훈음 설명이 없는 44자와 羲·暉·朗·曜 4자, 총 48자. 각 항목의 character와 codePoint를 원형대로 유지하고, contexts의 성어 독음과 뜻의 문맥을 참고하세요. 자료는 2026-10-30 기준이며 앱 데이터 원본 SHA-256은 JSON summary에 있습니다.

각 항목에서 훈음, 부수, 한국 학습용 총획을 가능한 범위로 조사하세요. 각각의 원문 직접 열람 URL, 확인한 항목, 열람 여부, 자료 제공자와 재사용 조건 URL을 기록하세요. 검색 요약만 본 것은 직접 열람이라고 표시하지 마세요. 모르는 값은 null로 두세요. 朗은 10획과 11획 자료가 충돌하므로 자형·실제 필획·원획 등 기준을 근거와 함께 구분하고, 해결할 수 없다면 null로 두세요.

nfkcResearchHint는 호환 한자 탐색 단서일 뿐 치환 허가가 아닙니다. 원문자와 단서의 훈음·자형·부수·획수 및 획순이 실제로 같은지 확인하기 전 데이터를 합치거나 동일하다고 확정하지 마세요. 같은 문자 코드포인트라도 지역별 자형과 획순이 다를 수 있습니다. Unicode의 kRSUnicode는 부수 분류값이며 부수 이름 자체가 아닙니다. kTotalStrokes는 한국 교육용 숫자로 자동 확정하지 마세요.

중요: 사이트의 무료 조회 가능 여부와 앱에 데이터를 복제·가공·상업적으로 재배포할 수 있는 권리는 다릅니다. 앱 이용 조건을 확인할 수 없으면 해당 값을 조사 참고로만 표시하고 재사용 가능으로 판단하지 마세요. 동일 출처의 재게시·동일 기원 데이터는 독립 교차 근거가 아닙니다.

출력은 다음 네 파일을 주세요. 기존 파일을 덮어쓰지 말고 새로운 결과로 만드세요.
1. review.json: 48자 모두에 대해 character, codePoint, 기존 값, 제안 값(훈음·부수 문자/이름·총획), 항목별 sourceIds, 판정(유지/수정/불확실), 이유, 미확인 사항. 확인하지 못한 값은 null.
2. sources.md: ID, 제공자, 개별 직접 URL, 확인 일자, 직접 열람/검색 요약/접근 실패 구분, 뒷받침하는 항목, 이용 조건 및 근거 URL, 제한.
3. issues.md: 출처 충돌·미확인·복수 음·이체자·획수 기준 및 우선 검토할 항목.
4. summary.md: 실제 조사한 범위, 검증 방법, 항목별 확인/미확인 수, 직접 열람 불가·실행하지 않은 검사.

마지막에 48자 누락·중복, 문자와 코드포인트 일치, sourceIds 유효성, JSON 문법을 실제로 검사하고 결과와 사용한 도구를 기록하세요. 웹 검색이나 원문 열람이 안 되면 그 사실을 표시하고 모델 기억으로 빈칸을 채우지 마세요.
```

GPT 웹은 로컬 파일을 자동으로 볼 수 없으므로 `priority-review.json`을 함께 첨부한다. 결과는 새 `data/hanja-research/pilot/gpt-priority/` 폴더에 보관한다. 원본 후보·기존 파일럿 파일은 덮어쓰지 않는다.
