# GPT 웹: 한국 한자 일괄 대조 자료 조사

아래 지시를 GPT 웹에 전달한다. GPT 웹은 로컬 파일을 자동으로 볼 수 없으며, 필요하면 `priority-review.json`을 별도로 첨부한다. 이번 조사는 데이터 전체를 만들거나 글자별 검수를 반복하는 일이 아니다.

```text
한국어 한자 학습 앱에서 훈음·부수·총획 후보를 일괄 대조할 자료를 조사해 주세요. 한자별 값을 생성하거나 기존 조사를 반복하지 말고, 공식 또는 원저작자가 제공하는 실제 데이터와 이용 조건을 확인해 주세요.

현재 상태: 학습 자료의 고유 한자 1,566자, libhangul 훈음 후보 1,522자, Unicode Unihan 17의 부수 분류·총획 후보 1,566자. 이 후보들은 한국 학습 기준 검수 전입니다. 호환 한자 38자에 NFKC 단서가 있으나 원문자를 자동 치환하지 않습니다. 朗은 한국어기초사전에 총획 11, Unihan에는 10이므로 별도 검토 중입니다.

찾는 것: 한국어 훈음·부수 문자/부수명·한국어 학습용 총획을 가능한 한 대량으로 제공하는 출처. 다운로드 가능한 데이터 또는 정식 API를 우선하세요. 별도의 한국식 획순 데이터가 있다면 별도 후보로 보고하세요.

각 후보마다 실제 원문 URL, 데이터 제공자·원천·버전, 직접 열람 여부, 데이터 형식·한자 범위·호환 문자 처리, 각 필드 지원 여부, 업데이트와 다운로드/API 접근 방식·요금/호출 한도를 기록하세요. 상업적 앱에 복제·가공·번들·재배포할 권한과 출처 표시·동일조건 등 의무를 해당 데이터의 라이선스 또는 약관 원문으로 확인하고, 확인 못한 것은 미확인으로 남기세요. 서비스 코드와 데이터의 라이선스를 혼동하지 마세요. 재게시 자료가 독립 검증인지도 확인하세요.

국립국어원 한국어기초사전과 libhangul, Unicode Unihan은 이미 후보로 확보되어 있습니다. 실제 대량 추출 가능 여부·필드 구성·해당 버전과 이용 조건을 추가 확인하세요. 크롤링이나 제한 우회는 제안하지 마세요. 사이트가 보이지 않으면 미열람으로 표시하고 기억으로 채우지 마세요.

source-candidates.md: 자료별 표와 각 사실을 뒷받침하는 직접 URL, 실제 확인 범위, 이용 조건 원문, 미확인 사항.
recommendation.md: 앱에서 사용 가능한지/판단 보류인지, 자동 대조 가능 범위, 비용·접근 제한, 朗 충돌 처리 및 남은 검수, 실제 실행한 검사.

같은 원본의 재게시를 독립 출처로 세지 말고, 검색 요약과 직접 열람을 구분하세요. 데이터 다운로드·API 호출을 수행하지 못했다면 실제로 수행했다고 쓰지 마세요.
```
