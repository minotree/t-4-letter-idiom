# 한국 한자 학습 앱 대량 대조 권고

기준일 2026-10-30. 이 문서는 **자료 출처 선정** 결과이며 개별 한자의 확정값이나 앱 패치를 포함하지 않는다.

## 결론

1. **Unihan 17.0: 사용 가능(기술적 후보 및 충돌 탐지용)**. 정적 ZIP으로 1,566 코드포인트 대조가 가능하고 데이터 복제·가공·상업적 배포 조건을 Unicode License v3에서 확인했다. 그러나 `kRSUnicode`는 부수 분류번호, `kTotalStrokes`는 한국 교육 표준이 아니다. 원본 값은 유지, 교육 확정 필드는 별도.
2. **libhangul hanja.txt: 조건부/판단 보류**. 기존 1,522자의 훈음 후보 생성용 데이터로 유지. 대용량 파일 페이지는 확인했으나 실제 파일 헤더를 열지 못해 BSD 3-Clause 적용을 원저작자 원본에서 검증하지 못했다. 프로젝트 코드 LGPL과 데이터 라이선스를 섞지 말 것.
3. **한국어기초사전: 한국어 문맥 교차확인용, 일괄 마스터로는 판단 보류**. 공식 XML 검색/상세 API와 하루 50,000회 한도 안내 확인. 개별 한자 대표 훈음/부수/총획을 1,566자 전부 한 번에 내려주는 공개 스키마는 확인하지 못했다. 텍스트 기본 라이선스는 CC BY-SA 2.0 KR, 출처 표시 및 파생저작물 동일조건 확인.
4. **표준국어대사전·우리말샘: 보조 검증용**. 정식 인증키 API(XML/JSON)로 한자어 표제어의 원어·뜻풀이 확인. 한자별 부수·총획 마스터 필드, 대량 제공 범위, 출처별 라이선스 예외 확인 전까지 자동 정답화 보류.
5. **AnimCJK: 별도 획순 후보**. 지역별 SVG 및 Arphic 라이선스 확인. 한국 `svgsKo`의 535자(저장소 설명 수치)로는 1,566자 전수 충족이 안 되며 개별 파일 존재와 표준 일치는 별개. SVG 이용 조건과 렌더러 LGPL을 혼동하지 말 것.

## 자동 대조 가능 범위

| 필드 | 자동 대조 소스 | 현재 확인 가능한 범위 | 교사·사전 기준 수동 대조 |
|---|---|---|---|
| 문자·코드포인트 | 기존 인벤토리 + Unihan 17 | 1,566자 기존 확보(사용자 제공 현황, 이번 재집계 미실행) | 호환 38자 별도 |
| 훈·음 | libhangul + 국립국어원 어휘 API | libhangul 후보 1,522자(사용자 제공 현황), API에서 한 글자 대표 훈의 완전한 회수율 미확인 | 다의·다음·훈의 서술 다름을 대조 |
| 부수 문자 | Unihan 부수 번호 + 공식 부수기호 매핑 | 분류 후보 1,566자, 부수명 텍스트는 별도 사전 필요 | 한국 표준 부수 및 이체 부수 대조 |
| 부수명 | 별도 한국어 원천 필요 | **공식 일괄 필드 출처 미확보** | 전문 검수 |
| 한국 학습용 총획 | Unihan `kTotalStrokes`는 불일치 탐지 참고 | 일반 획수 후보 1,566자, 한국 교육값 검증 건수 0(이번 조사 미실행) | 실제 자형·획 셈 기준 확정 |
| 획순 | AnimCJK 한국 SVG | 프로젝트 설명상 한국 폴더 535자; 교집합 미실행 | 재생 및 한국식 획순 기준 확인 |

## 朗 충돌 정책
- 한국어기초사전 개별 원문(이전 조사) 11획과 Unihan 17 후보 10획은 *서로 다른 기록*으로 유지. 11이나 10으로 강제 병합하지 않는다.
- 구분할 조사축: 같은 U+6717인지, 폰트/지역별 자형인지, 표제어의 필획·원획 표기 규칙인지, 실제 교재의 획 세기인지. 2개의 수치와 원문 URL을 개별 보존.
- 한국 교육용 값은 **null**로 유지. 한국 표준 학습 사전의 기준 설명과 획별 실제 필획 확인 후에만 확정.

## 비용·접근 제약
- Unihan: 정적 공개 ZIP, 별도 인증키 불필요, 데이터 자체 사용료 확인되지 않음. 다운로드 시 네트워크 비용은 별도.
- libhangul: 공개 리포지터리 파일. 원본 6.15MB를 웹 열람기로 직접 펼칠 수 없어 헤더 검증 미완료. 호출 API 아님.
- 한국어기초사전: 이메일 키 발급, 공식 신청 페이지에 하루 50,000회 안내. 키 미발급/호출 미실행. 서비스 무료 안내는 데이터 라이선스와 별개.
- 표준국어대사전·우리말샘: 키 신청 필요. 구체적인 일일 한도/요금은 이번 원문 확인 범위에서 미확인.
- AnimCJK: 정적 파일. 제공 웹서비스의 가용성·브라우저 SVG 호환성·한국 교육 기준 검증은 별도.

## 실제 수행 및 미실행 검사
- 실행: 공식 웹페이지 검색, 원문 열람(국립국어원 3종 API 안내·저작권 정책, libhangul 저장소/파일 목록, Unicode 17 배포 디렉터리/라이선스, AnimCJK README/라이선스 전문), URL 및 필드 비교.
- 미실행: Unihan.zip 다운로드/압축 해제, libhangul hanja.txt 원본 본문 분석(원본 접근 시 크기 제한 오류), 사전 인증키 발급/호출, API 별 총 반환건수 집계, 1,566자 실매칭, 38 호환자 자형 동등성 대조, 한국 총획 전수 검수, SVG 획순 실행/오프라인 재생.
- 버전: 과거 조사 SHA-256 원본값을 재계산하지 않았으며, Unihan 17 URL을 고정하되 당시 UAX 38 고정판은 별도 열람하지 못함.

## 실무 순서
(1) libhangul 원본 파일 헤더의 데이터 라이선스 확인 → (2) 한국어기초사전 API 테스트 키로 출력 샘플의 정확한 한자 필드/목록 범위 확인 → (3) 공식 한국 부수명·교육획수 대량 데이터의 실제 제공 여부 추가 확인 → (4) 기존 후보와 한국 원문 불일치만 사람 검수 → (5) 朗 및 호환 한자 별도 판정. 자동 수집은 공식 다운로드/API 허용 범위에서만.
