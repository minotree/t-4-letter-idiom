# 개별 한자 정보 기능 보류 (2026-10-30)

후속: 음·훈만 제공하는 기능은 같은 날짜에 새로 구현해 재개했다. 현재 구현은 `apps/*/src/HanjaCardHeading.tsx`, 데이터·검토 범위는 `data/hanja-readings/` 참조. 이 폴더의 부수·획수·SVG 획순 코드는 계속 보관 상태다.

사용자 요청에 따라 개별 한자 정보 팝업·획순 기능을 PWA·토스 배포 빌드에서 제외했다. 원래 각 앱에 있던 컴포넌트·SVG·고지 파일은 이 폴더의 `apps/` 아래에 보관한다. 각 스타일 블록은 `HanjaCardHeading.css`로 보존했다. 실험용 실행 도구도 `preview-hanja-pilot.mjs`로 보관했다.

이 파일들은 현재 앱이 import하지 않고 Vite public 디렉터리 밖에 있으므로 배포 산출물에 들어가지 않는다. 독립 연구 시제품 `../pilot/svg-local/card-pilot.html`, 출처·검수 기록 및 원본 자료는 보존한다. 보관된 시험용 스크립트는 실제 앱에서 팝업을 제거한 현재 빌드와 그대로 호환되지 않으므로 재개 시 경로와 앱 연결을 다시 검토한다.

영어 단어·예문 TTS는 보류 대상이 아니다. 한자 기능 재개 시 기존 요구사항·라이선스·기기 검증·기록과 사용자 승인 범위를 다시 확인한다.
